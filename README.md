## Опис проєкту
Консольний Java-застосунок для обліку транзакцій на заправці. Проєкт демонструє використання об'єктно-орієнтованих принципів (інкапсуляція, спадкування, поліморфізм), перелічуваних типів (`enum`), перевизначення методів `equals`/`hashCode`, а також автоматичного тестування та статичного аналізу коду.

## Архітектура (ЛР3)
- **`FuelTransaction`** — абстрактний базовий клас із спільними полями (`date`, `column`, `kind`, `liters`) та абстрактним методом `calculateCost()`.
- **`PetrolTransaction`** — підтип для транзакцій бензину (враховує 2% знижки за наявності картки лояльності).
- **`DieselTransaction`** — підтип для транзакцій дизелю (враховує 5% знижки для гуртових замовлень > 100 л).
- **`FuelKind`** — `enum` для фіксованих категорій пального (`PETROL`, `DIESEL`).
- **`TransactionFactory`** — фабричний клас для створення конкретних підтипів із CSV-рядка.
- **`FuelController`** — контролер, що обробляє поліморфну колекцію `List<FuelTransaction>` без умовних операторів `if`/`switch`.
