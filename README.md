# Аналіз даних заправки (Варіант 24)

## Призначення
Програма читає записи про продаж пального з `data/input.csv`, перевіряє їх на коректність, обчислює кількість проданих літрів, загальну вартість та середню ціну літра, а потім формує звіт у консоль і файл `out/report.txt`.

## Формат входу
Один запис розміщують у рядку, поля розділяють крапкою з комою (тип пального; літри; ціна за літр; дата; номер колонки). Файл кодують у UTF-8.
